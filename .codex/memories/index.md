# Nice Books 项目记忆

## 使用入口

- 日常维护先读根目录 [AGENTS.md](../../AGENTS.md)。源码、命令和设计契约分别以实际文件及其指向的文档为准。
- 接管迁移、核对发布阶段、查询历史验收或跨项目边界时，读 [2026-11-13 迁移交接记忆](2026-11-13-migration-handoff.md)。其中“长期决定”保存约定，“状态快照”保存该日观测。
- 查询首次建仓、Pages 配置和发布证据时，读 [2026-11-13 首次 Pages 发布](2026-11-13-first-pages-release.md)，并回读其中链接的 #157 结果评论核对最终提交、运行及票状态。
- 查询首次独立站线上验收、自然字体实测或线上 404 证据时，读 [2026-11-13 T5 线上验收](2026-11-13-t5-online-acceptance.md)，以及 [T5 验收记录](../../docs/t5-acceptance.md)。
- 当前 Git、GitHub 票册和部署情况按交接记忆中的命令重新查询。有日期的结果只证明对应时间及条件下的状态。

## 维护方式

- 新决定或阶段完成后，在本目录添加有日期的记忆，并更新本索引。每项记录注明来源文件、对应提交或 issue，以及验证范围与待核验事项。
- 历史测量保留原值，后续观测写明日期及差异。长期规则变化时同步根目录说明与实际契约文档。
- 提交内验收摘要是其他检出的证据入口。本机忽略目录 `output/` 的日志、截图和账本供深入追溯，其可用性需在当前机器核对。
